Configurar Sheetson

Completa estos 3 datos con la información que aparece en tu panel de Sheetson. La configuración queda guardada solamente en este navegador.

Es el ID largo que aparece en el panel de Sheetson o en la URL de Google Sheets.

Debe coincidir exactamente con el nombre de la pestaña de Google Sheets.

Para esta versión, la API Key se guarda en el navegador y se usa desde la página. No publiques esta página como un sitio abierto si necesitas mantener esa clave privada.

Conectar tu Google Sheet con Sheetson

Tu pantalla nueva de Sheetson muestra tres datos que necesitamos: API Key, ID de la hoja de cálculo y Nombre de la hoja.

  1. 1 En Google Sheets, usa la pestaña que contiene los casos y deja en la primera fila estos encabezados: id, fechaRecepcion, empresa, canal, cliente, producto, serie, sku, fechaVenta, documento, marca, motivo, monto, tipoFalla, estado, tipoAlmacen, solucion, fechaRespuesta, observacion, tiempoAtencion, rangoAtencion.
  2. 2 En tu panel de Sheetson, copia la API Key, el ID de la hoja de cálculo y el Nombre de la hoja. La API actual usa el nombre de la pestaña en la ruta y el ID de la hoja de cálculo en el encabezado X-Spreadsheet-Id.
  3. 3 En cada laptop, pulsa Configurar Sheetson, coloca esos tres datos y pulsa Guardar y conectar.
  4. 4 El sistema consultará automáticamente la hoja cada 10 segundos cuando estés viendo el listado o el dashboard. Sheetson no ofrece sincronización en tiempo real, por lo que aquí usamos consulta periódica.
La API de Sheetson usa POST para crear filas y PUT con el número de fila para actualizar una fila existente. Esta versión del sistema ya está preparada para eso.
